This repo is a convenience repo for getting all my configurations.

If you have an existing .config with other configurations you care to keep instead of cloning the repo do
`cd ~/.config && git init` to set up your own blank repo in the folder and `git remote add origin https://github.com/novajacobsen/.config.git`
You may still have to delete existing configurations before you can `git pull main` if there's an overlap, but the error message should be helpful indentifying what.
